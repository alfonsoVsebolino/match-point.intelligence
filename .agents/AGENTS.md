# Project Guidelines

### Interview & Clarification Protocol
- **Sequential Inquiries**: Present questions strictly **one by one per round**. Never batch multiple decisions (e.g. Q1, Q2, Q3) in a single turn.
- **Single Frontier Advance**: Post exactly one decision with options and recommended answer (`➡️`). Wait for user response before generating the subsequent question.
