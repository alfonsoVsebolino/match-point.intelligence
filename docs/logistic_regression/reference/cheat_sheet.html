Regularized Logistic Regression Reference Cheat Sheet

1. Mathematical Formulas

Log-Odds (Logit):

$$z = w^T x + b = \sum_{j=1}^d w_j x_j + b$$

Sigmoid Hypothesis:

$$p = P(y=1|x) = \sigma(z) = \frac{1}{1 + e^{-z}}$$

L2-Regularized Binary Cross-Entropy (Scikit-Learn Objective):

$$\min_{w, b} \left\{ \sum_{i=1}^n \left[ -y_i \ln(p_i) - (1 - y_i) \ln(1 - p_i) \right] + \frac{1}{2C} \sum_{j=1}^d w_j^2 \right\}$$

Gradient with respect to logit:

$$\frac{\partial J}{\partial z_i} = p_i - y_i$$

4. Scoring Metrics Cheat Sheet

  • Log-Loss: \(-\frac{1}{n}\sum [y_i \ln p_i + (1-y_i)\ln(1-p_i)]\) — primary calibration loss.
  • Brier Score: \(\frac{1}{n}\sum (p_i - y_i)^2\) — quadratic penalty, benchmarked vs bookmaker.
  • ROC-AUC: Probability that winner receives higher win-probability than loser. Random = 0.50, Model = 0.7120.
